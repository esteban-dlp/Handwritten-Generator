# Contributing

Use Python 3.10+ and run `python -m unittest discover -s tests -v` before submitting a pull request. Add regression tests for layout, punctuation and sample selection changes. Use synthetic fixtures and no personal handwriting. Keep docs in English and explain behavior changes and limitations. Avoid machine-specific paths, generated PDFs and user libraries in commits. The allowlist in .gitignore deliberately excludes root-level legacy/private files; stage only intended source paths. Contributions are under the repository's MIT license.
